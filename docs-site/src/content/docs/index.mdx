import { Card, CardGrid } from '@astrojs/starlight/components';

## Why Strata

<CardGrid>
  <Card title="Tree-first" icon="list-format">
    Indented, multi-level tree grid out of the box — for file explorers, org
    charts, category trees, or any nested data.
  </Card>
  <Card title="Virtualized" icon="rocket">
    Row *and* column virtualization for datasets in the tens of thousands.
  </Card>
  <Card title="Themable" icon="setting">
    CSS-custom-property tokens, dark mode, density presets, and print support.
  </Card>
  <Card title="Free & open" icon="open-book">
    Apache-2.0 licensed; no paywalled tree-grid, no enterprise tier.
  </Card>
</CardGrid>

## Built for the enterprise landscape

Strata fits naturally wherever hierarchical, transactional, or master data
shows up in business systems:

<CardGrid>
  <Card title="PLM" icon="puzzle">
    Bills of materials, where-used analyses, multi-level part hierarchies,
    engineering change orders.
  </Card>
  <Card title="ERP" icon="document">
    Chart of accounts, organization hierarchies, project WBS, inventory
    rollups, approval workflows.
  </Card>
  <Card title="CRM" icon="forward-slash">
    Account/contact trees, opportunity pipelines, territory hierarchies,
    nested case histories.
  </Card>
  <Card title="And more" icon="setting">
    Asset hierarchies (EAM), category trees (e-commerce), org charts (HRIS),
    nested permissions (IAM), file/folder views.
  </Card>
</CardGrid>
