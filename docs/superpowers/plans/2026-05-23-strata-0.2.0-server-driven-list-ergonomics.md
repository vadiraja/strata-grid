## Goal

Ship `strata-grid@0.2.0-alpha.0` with three additive enhancements to `<DataGrid>` that close real friction points reported by ProtoTrack during their server-driven Suppliers list spike. No breaking changes.

## Scope

1. **Typed column filter configs** — `ColumnDef.filter` accepts a config object with `type`, `operators`, and type-specific fields (options, multi, range). UI renders the right input per type; emitted `FilterExpression` uses constrained operators only.
2. **`onPaginationChange` callback** — surfaces `{ currentPage, pageSize, totalCount, totalPages, isLoading, error }` from `<DataGrid>` so consumers can drive shell-rendered status bars without an adapter-side subscribe seam.
3. **First-class `rowActions` prop** — renders a built-in actions column with inline/kebab display, conditional visibility/disabled, and keyboard accessibility. (Lower confidence — may iterate based on subsequent spike feedback.)

## Non-goals

- Custom filter UI escape hatch (`type: 'custom'`) — push to 0.3.0
- Async `loadOptions` for `type: 'select'` — pending ProtoTrack answer to open question
- Foreign-key `lookup` filter type — pending ProtoTrack answer
- Discrete `onSortChange` / `onFilterChange` / `onSearchChange` callbacks — didn't surface as friction
- Breaking changes to existing `ColumnDef.filter` consumers

## Architecture

**Type extension only — runtime stays unchanged for the string shortcut path.**

```ts
// src/data/types.ts — extends existing FilterOperator union, adds ColumnFilterConfig
export type ColumnFilterConfig<TValue = unknown> =
  | 'text'
  | 'number'
  | { type: 'text'; operators?: FilterOperator[] }
  | { type: 'number'; operators?: FilterOperator[] }
  | { type: 'select'; options: SelectOption<TValue>[]; multi?: boolean; operators?: FilterOperator[] }
  | { type: 'boolean' }
  | { type: 'date'; operators?: FilterOperator[]; range?: boolean };

export interface SelectOption<TValue = unknown> {
  label: string;
  value: TValue;
}
```

The grid's filter UI (`HeaderFilterButton` or equivalent) reads the config, resolves to a filter type, and renders the right input. Existing string shortcuts (`'text'`, `'number'`) resolve to `{ type: 'text' }` / `{ type: 'number' }` internally.

`rowActions` is a synthetic pinned column inserted by `<DataGrid>` before `normalizeColumns`. Internal implementation only — no impact on the user's `columns` array.

`onPaginationChange` is a `useEffect` watching `paginationState` inside `DataGrid`. Fires whenever any tracked field changes.
