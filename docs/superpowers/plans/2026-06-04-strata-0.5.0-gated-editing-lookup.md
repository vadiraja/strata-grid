# Strata 0.5.0 — Gated editing, modal editor surface & enterprise lookup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an opt-in whole-grid edit-mode gate, a per-column modal editor surface, a searchable async lookup editor with declarative cascade-fill, opt-in auto-apply data write-back, and mode-agnostic cell-value undo/redo — all non-breaking for existing consumers.

**Architecture:** Five layered parts built on the existing editing stack (`EditableConfig`, `editors/`, `use-edit-state`, `use-validation`, fill handle). A single new boolean `editingEnabled` carried on `EditContextValue` gates every activation site. A new grid-level `EditModalHost` portal (the codebase's first true modal) renders the *same* editor a cell would, selected by a new `ColumnDef.editSurface`. A new `LookupEditor` combobox (text input + portalled async result list) backs `editorType: 'lookup'`, and its selection writes the cell plus declarative `map` cascades through a new transactional multi-cell apply path. Write-back and undo/redo are wired at the single `useEditState` commit seam in `DataGrid.tsx` plus the `onFillRange` seam in `GridRoot.tsx`.

**Tech Stack:** React 18 + TypeScript, Vitest + @testing-library/react (jsdom), tsup build. No new runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-06-03-strata-0.5.0-gated-editing-lookup.md`

## Locked design decisions (read first)

These resolve ambiguities the spec left open; later tasks depend on them being consistent.

- **DD1 — Gate location.** Add `editingEnabled: boolean` to `EditContextValue` (`src/model/edit-context.ts`). DataGrid computes it (controlled `editing` prop or uncontrolled state, default `true`) and passes it into the provider value. Every activation site reads it from `useEditContext()`. The existing all-or-nothing "no `editable` ⇒ no provider" behavior is unchanged; the gate is a *second, finer* switch that keeps edit state mounted but suppresses activation.
- **DD2 — `showEditableIndicator`.** Wire the existing-but-unused `EditableConfig.showEditableIndicator` (default `true`) in the same task as the gate. The indicator class is hidden when the gate is off **or** `showEditableIndicator === false`.
- **DD3 — Modal surface routing.** Add `ColumnDef.editSurface?: 'inline' | 'modal'` (default `'inline'`). Inline keeps today's behavior (`<CellEditor>` mounted in `DataCell`). For `'modal'`, `DataCell` renders normal content (no inline editor) and a single grid-level `EditModalHost` portals a dialog hosting the same editor. Extract the editor-rendering branch from `CellEditor.tsx` into a shared `renderActiveEditor(...)` so inline and modal render identically.
- **DD4 — Multi-cell transactional apply.** Add `applyCellEdits(rowId, edits, opts?)` to `EditStateReturn` (in `use-edit-state.ts`) that writes N columns of one row into `dirtyState` in a single batch and fires a new `onCellsChange` event once. The lookup cascade and (later) write-back/undo all funnel through this. Cell value + cascade = one `onCellsChange` event = one undo entry.
- **DD5 — Row addressing for write-back.** Add optional `getRowId?: (row: TRow) => string` to `DataGridProps` for flat grids. Auto-apply uses, in priority order: `treeData.getRowId` (tree mode) → `getRowId` prop → `(row) => String(row.id)` fallback. The grid edit/`rowId` scheme is unchanged; `getRowId` is only used by auto-apply to locate the row to update in the supplied `data` array.
- **DD6 — Cell-value undo/redo is its own mode-agnostic stack.** A new `useCellHistory` hook keeps an ordered stack of cell-snapshot transactions (each = `{ rowId, edits: {columnId, prevValue, nextValue}[] }`). It is independent of the tree-structural history. Bind `Ctrl/Cmd+Z` / `Ctrl/Cmd+Shift+Z` to cell history **only when not in tree-edit mode** (tree mode keeps its existing structural undo to avoid conflating two histories — unified history is a documented 0.5.x follow-up). Undo/redo apply through the same `applyCellEdits` path (controlled: re-emits `onCellsChange`; auto-apply: also mutates the array).

**Key facts for the engineer:**
- Run all tests: `npx vitest run`. One file: `npx vitest run <path>`. Typecheck: `npm run typecheck`. Build: `npm run build`.
- Never hand-edit `dist/` (gitignored; regenerated by `npm run build`).
- jsdom has no layout engine. Tests assert classes/DOM/callbacks, not computed geometry. Use `Object.defineProperty` to stub `clientWidth`/`scrollWidth` only if a test truly needs overflow (most don't).
- The live `onCellEditEnd`/`onRowEditEnd` payloads use the inline shapes (no `row` field): `onCellEditEnd({ rowId, columnId, value, newValue, committed })`. Match these exactly.
- Public exports live in `src/index.ts` — every new public type must be exported there.

```ts
const applyCellEdits = useCallback((rowId, edits, opts) => {
  if (edits.length === 0) return;
  setDirtyState((prev) => {
    const next = new Map(prev);
    const rowMap = new Map(next.get(rowId) ?? []);
    for (const e of edits) rowMap.set(e.columnId, e.newValue);
    next.set(rowId, rowMap);
    return next;
  });
  onCellsChange?.({ rowId, edits, source: opts?.source ?? 'edit' });
}, [onCellsChange]);
```

```tsx
import type { EditorContext, ColumnDef } from '../../model/types';
import { renderBuiltInEditor, inferEditorType } from './CellEditor'; // export these from CellEditor

export function renderActiveEditor<TRow>(
  ctx: EditorContext<TRow>,
  column: ColumnDef<TRow>,
  opts: { autoFocus: boolean; onNavigateKey?: (e: React.KeyboardEvent) => boolean },

  if (column.editor) return column.editor(ctx);

    column.editorType ?? inferEditorType(ctx.value),

    column.editorOptions, opts.autoFocus, opts.onNavigateKey,

}
```

```tsx
// src/components/EditModalHost.tsx
import { useEffect, useRef, useState } from 'react';
import { createPortal } from 'react-dom';
import { useEditContext } from '../model/edit-context';
import { renderActiveEditor } from './editors/renderActiveEditor';
import { useValidation } from '../model/use-validation';
import type { ColumnDef, EditorContext } from '../model/types';

interface EditModalHostProps<TRow> {
  /** The active column resolver: maps the active columnId to its ColumnDef + row. */
  getActiveTarget: () => { column: ColumnDef<TRow>; row: TRow; rowId: string; value: unknown } | null;
  portalTarget: HTMLElement | null;
}

export function EditModalHost<TRow>({ getActiveTarget, portalTarget }: EditModalHostProps<TRow>) {
  const editCtx = useEditContext<TRow>();
  const dialogRef = useRef<HTMLDivElement>(null);
  const target = editCtx?.editState.activeCell ? getActiveTarget() : null;
  const isModal = !!target && target.column.editSurface === 'modal';

  const [draft, setDraft] = useState<unknown>(target?.value);
  useEffect(() => { setDraft(target?.value); }, [target?.rowId, target?.column.id]);

  const { validation, validateNow } = useValidation({
    validate: target?.column.validate, value: draft, row: target?.row as TRow,
  });

  useEffect(() => {
    if (!isModal) return;
    dialogRef.current?.focus();
    const onKey = (e: KeyboardEvent) => { if (e.key === 'Escape') cancel(); };
    document.addEventListener('keydown', onKey);
    return () => document.removeEventListener('keydown', onKey);
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [isModal]);

  if (!isModal || !editCtx || !portalTarget || !target) return null;

  const commit = async () => {
    const result = await validateNow();
    if (result.status === 'invalid') return;
    editCtx.editState.setPendingValue(draft);
    editCtx.editState.commitEdit();
  };
  const cancel = () => editCtx.editState.discardEdit();

  const editorContext: EditorContext<TRow> = {
    value: draft, row: target.row, column: target.column, rowId: target.rowId,
    onChange: setDraft, onCommit: commit, onDiscard: cancel, validation,
  };

  return createPortal(
    <div className="strata-modal-backdrop" onPointerDown={cancel}>
      <div
        ref={dialogRef}
        role="dialog"
        aria-modal="true"
        tabIndex={-1}
        className="strata-modal"
        onPointerDown={(e) => e.stopPropagation()}
      >
        <div className="strata-modal-header">{String(target.column.header ?? target.column.id)}</div>
        <div className="strata-modal-body">
          {renderActiveEditor(editorContext, target.column, { autoFocus: true })}
        </div>
        <div className="strata-modal-footer">
          <button type="button" className="strata-modal-cancel" onClick={cancel}>Cancel</button>
          <button
            type="button"
            className="strata-modal-commit"
            disabled={validation.status === 'invalid' || validation.status === 'validating'}
            onClick={commit}
          >Save</button>
        </div>
      </div>
    </div>,
    portalTarget,
  );
}
```

```ts
// src/model/apply-cell-edits-to-rows.ts
import type { CellEditDelta } from './types';

export type CellWriter<TRow> = (row: TRow, value: unknown) => TRow;

export function applyCellEditsToRows<TRow>(
  rows: TRow[],
  rowId: string,
  edits: CellEditDelta[],
  getRowId: (row: TRow) => string,
  getWriter: (columnId: string) => CellWriter<TRow> | undefined,
): TRow[] {
  const index = rows.findIndex((r) => getRowId(r) === rowId);
  if (index < 0) return rows;
  let updated = rows[index];
  for (const e of edits) {
    const writer = getWriter(e.columnId);
    if (writer) updated = writer(updated, e.newValue);
  }
  if (updated === rows[index]) return rows;
  const next = rows.slice();
  next[index] = updated;
  return next;
}
```

```ts
// src/model/use-cell-history.ts
import { useCallback, useRef, useState } from 'react';
import type { CellEditDelta } from './types';

export interface CellTransaction { rowId: string; edits: CellEditDelta[]; }
interface ApplyArg extends CellTransaction { source: 'undo' | 'redo'; }

export function useCellHistory(opts: { apply: (t: ApplyArg) => void; depth?: number }) {
  const depth = opts.depth ?? 50;
  const [undoStack, setUndoStack] = useState<CellTransaction[]>([]);
  const [redoStack, setRedoStack] = useState<CellTransaction[]>([]);
  const applyRef = useRef(opts.apply);
  applyRef.current = opts.apply;

  const record = useCallback((t: CellTransaction) => {
    setUndoStack((prev) => {
      const next = [...prev, t];
      return next.length > depth ? next.slice(next.length - depth) : next;
    });
    setRedoStack([]);
  }, [depth]);

  const undo = useCallback(() => {
    setUndoStack((prev) => {
      if (prev.length === 0) return prev;
      const t = prev[prev.length - 1];
      applyRef.current({ rowId: t.rowId, edits: t.edits.map((e) => ({ columnId: e.columnId, oldValue: e.newValue, newValue: e.oldValue })), source: 'undo' });
      setRedoStack((r) => [...r, t]);
      return prev.slice(0, -1);
    });
  }, []);

  const redo = useCallback(() => {
    setRedoStack((prev) => {
      if (prev.length === 0) return prev;
      const t = prev[prev.length - 1];
      applyRef.current({ rowId: t.rowId, edits: t.edits, source: 'redo' });
      setUndoStack((u) => [...u, t]);
      return prev.slice(0, -1);
    });
  }, []);

  const canUndo = useCallback(() => undoStack.length > 0, [undoStack]);
  const canRedo = useCallback(() => redoStack.length > 0, [redoStack]);

  return { record, undo, redo, canUndo, canRedo };
}
```
